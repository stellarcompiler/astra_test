# Rules

- Design for 360px first.
- Scale upward using breakpoints.
- Prefer Flexbox and CSS Grid.
- Use relative spacing.
- Use clamp() for typography.
- Avoid fixed heights.
- Avoid horizontal scrolling.
- Test layouts mentally for phone, tablet and desktop.

## Priority

Mobile > Tablet > Desktop
